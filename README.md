# Amazon Logistics - Data Analysis Study

## Problem
Amazon's logistics sector experienced a critical decline 
in on-time delivery performance (OTIF: 61.9% vs 97% target).

## Objective
Identify root causes and propose data-driven solutions.

## Tools
- Excel (data analysis)
- Power BI (interactive dashboard)
- PowerPoint (executive presentation)

## Key Findings
- BudgetExpress: 50.82% OTIF at the same cost as FastShip
- FC-C alone responsible for 53% of all delays
- Prime customers paying 35% more for the same poor service

## Solutions Proposed
1. Carrier Management — reduce BudgetExpress volume
2. FC-C Optimization — redistribute volume and expand capacity
3. Prime First — prioritize Prime deliveries and SLA
